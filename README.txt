我的錢錢小管家 v4｜兒童理財成長版

新增功能：
1. 任務賺零用錢
   - 可以新增任務
   - 設定獎勵金額
   - 完成後自動加入指定錢包

2. 多個存錢願望
   - 可以同時建立多個願望
   - 每個願望有自己的目標金額與進度
   - 可以放圖片
   - 達標會解鎖成就

3. 錢包轉帳
   - 可以花 / 存起來 / 分享 三個錢包互相轉帳

4. 成就牆
   - 第一筆、5 筆紀錄、存錢豬、任務達人、會分配、願望達成、記帳高手

5. 每月回顧卡
   - 每月收入
   - 每月花費
   - 每月存款
   - 需要 vs 想要
   - 自動產生簡單的理財回顧訊息

6. 自動承接舊版
   - 會嘗試承接 v3 / v2 的本機資料
   - 舊版單一願望會轉成 v4 的第一個願望
