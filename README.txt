我的錢錢小管家 v6｜進階成長版

本版新增：
1. 花費排行榜
   - 依月份統計
   - 依分類由高到低排序
   - 首頁顯示前三名
   - 月回顧顯示完整排行榜

2. 願望預估達成日
   - 優先依最近 90 天該願望的實際存入速度估算
   - 若尚無該願望存款紀錄，改用最近 90 天「存起來」收入速度估算
   - 尚無足夠紀錄時顯示「先存幾次後就能估算」

3. 任務／願望完整管理
   - 任務可編輯、刪除
   - 願望可編輯、刪除
   - 刪除有已存金額的願望時，金額會退回「存起來」

4. 兒童安全 PIN
   - 可設定 4～6 位數字 PIN
   - PIN 開啟後，刪除任務、刪除願望、匯入備份、清除全部資料、關閉 PIN 都需要驗證
   - 不會把 PIN 傳到雲端，僅存在這台裝置

5. 深色模式／主題顏色
   - 亮色／深色
   - 粉紅／淡紫／天空藍／薄荷綠

6. 自動承接 v5 / v4 / v3 / v2 資料
