上傳到 GitHub Pages：

1. index.html
2. manifest.webmanifest
3. sw.js
4. icon-192.png
5. icon-512.png

上傳完成後 GitHub Pages 會自動更新，網址不用改。

注意：

換手機或清除瀏覽器資料前，請先匯出備份。
